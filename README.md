# Microsoft 365 Copilot Chat 障害解析 Skill

トレースログを SharePoint 上の製品資料と照合し、原因仮説を検討する個人 Skill です。実装の確認が必要なときは、利用者が調査依頼をソースコードへアクセスできるコーディングエージェントに渡し、結果を元のチャットに戻します。

製品担当者は [導入・利用ガイド](docs/setup-and-use.md) から始めてください。[共通 SKILL.md](skills/product-incident-analysis/SKILL.md) の「製品設定」欄が設定テンプレートです。製品向けのコピー、SharePoint の参照先、実案件のログと調査結果は製品側の非公開環境で管理します。
